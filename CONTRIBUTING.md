# Contributing

Issues are welcome: bug reports, questions and suggestions all help. Use the issue forms; they ask for the plugin and SDK
versions, your harness, operating system and the command run id. The `/plurai-diagnose` skill and `plurai diagnose`
print most of that in a form you can paste.

This project does not accept outside pull requests. The public repository is a read-only mirror of the released files and
has pull requests turned off. Describe the problem, or the change you have in mind, in an issue instead.

To report a security problem, follow [SECURITY.md](SECURITY.md) and do not open a public issue.
